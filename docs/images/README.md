# Screenshots

Screenshots used by the root README and the guides. They were taken in the macOS release build (2.1.0) in a folder made for
the demo, with the built-in model. The interface on Linux is the same; nothing here was re-shot for 2.2.3.

| File | Shows |
|---|---|
| `requests.png` | A CSV total, the last errors in a log, and the suggestions for a bare `>bluetooth` |
| `terminals.png` | "what's running in my terminals" with a server running in another tab |
| `chain.png` | A multi-step request that made a folder, a git repository and `package.json` |
| `flow-approval.png` | The approval dialog for a `.flow` file (runs only after a click on Run) |
| `flow-run.png` | The same flow typed into the terminal step by step |
| `settings.png` | Settings: which AI answers requests |
| `by-name.png` | Opening a folder by name, with a question when two match |
| `make-workflow.png` | Choosing where to save a new `.flow` file |
| `run-workflow.png` | The approval dialog for running a saved workflow |
| `workflow-finished.png` | The terminal after a `.flow` finished: "finished: 5 steps" |
| `close-port.png` | An approval for `kill` on a port. This is the older centered dialog; since 2.2.3 approvals are a card in the bottom-right corner |

The demo video and GIF are in [`../media`](../media).
